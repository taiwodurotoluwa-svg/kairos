## 1. Official 100-Point Judging Rubric (`OPEN--BUILD-2026-Challenge-Brief.pdf`, Page 5, §9)

| Criterion | Official Wording | Weight |
| :--- | :--- | :--- |
| **1. Problem understanding and usefulness** | Clarity of the problem, understanding of intended users, and usefulness of the proposed solution. | **25 pts** |
| **2. Working prototype and technical execution** | Whether the core functionality works and how effectively the team implements its solution. | **25 pts** |
| **3. Meaningful use of an open-weight model** | How the model contributes to the solution and the thoughtfulness of the team's model choices. | **20 pts** |
| **4. Creativity and thoughtful design** | Originality of the approach, quality of the user experience, and suitability of the design. | **15 pts** |
| **5. Open-source practices and documentation** | Repository quality, README, licensing, acknowledgements, and reproducibility. | **15 pts** |
| **TOTAL** | Judges weigh understanding, effectiveness, and documentation over size. | **100 pts** |

* **Special Awards (Page 6, §10 — ₦50,000 pool):**
  * **Best Open-Source Practice** (₦20,000)
  * **Most Creative Solution** (₦15,000)
  * **Community Impact Award** (₦15,000)
